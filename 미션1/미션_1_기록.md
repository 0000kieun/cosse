## AI가 물어서 내가 정한 것:

### 사용자 / 데이터
- **사용자 대상**: 동아리 친구들 (닉네임 입력 방식)
- **저장 방식**: 로컬스토리지 (브라우저 닫아도 유지)

### 등급 체계
- **등급 단계**: S / A / B / C / 미관람 (5단계)

### 레이아웃
- **화면 구성**: 상단 입력창 → 하단 5개 티어 섹션

### 영화 목록
- **기본 제공**: 영화 20개 미리 등록
- **추가/삭제**: 사용자가 직접 추가·삭제 가능
- **입력 방식**: 텍스트 입력 + Enter 또는 버튼 둘 다 지원

### 카드 동작
- **순서 변경**: 카드 하단 ← → 버튼 (같은 등급 내 이동)
- **삭제**: 각 카드 우측 X 버튼
- **등급 이동**: 카드 클릭해 선택 → 티어 빈칸/표시칸 클릭해 이동

### 기타 기능
- **초기화**: 평가 리셋 기능 (영화는 미관람으로 복귀)
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
 기획서.md를 주었을때 오류없이 동작되기를 원하였으나,
 A에서는 클릭후 이동이 안되는, B에서는 닉네임 입력페이지를 첫화면에 띄웠으나 입력 후 다음 페이지로 넘어가지 않아
 기획서를 수정하여 다시 코드 생성을 요구하였다.
- 선택한 파일명과 고른 이유:
영화_B_초안_수정본.html
