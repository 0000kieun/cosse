# 미니멀 활동 기록 캘린더

## 대상 사용자
- 모바일 환경을 포함하여 일상을 간단하고 직관적으로 기록하고 싶은 누구나

## 사용 목적
- 날짜별로 아이콘과 색상을 활용하여 활동을 기록하고, 이를 시각적으로 확인하거나 이미지 파일로 간편하게 공유하기 위함

## 화면 구성과 동작
- **월간/주간 뷰:** 기본은 월간 뷰이며, 날짜 클릭 시 해당 날짜가 포함된 주(일~토)의 주간 뷰로 전환 가능
- **날짜 칸:** 왼쪽 상단에 날짜 숫자 배치, 배경은 선택한 파스텔톤 색상 적용 (모바일 최적화된 터치 영역 및 최소 높이 반영)
- **데이터 입력:** 날짜 클릭 시 팝업(모달) 호출. 아이콘(최대 5개)과 색상 선택 가능 (모바일에서는 하단 시트 형태로 최적화)
- **아이콘 배치:** 숫자 아래에 아이콘 나열. 메인 큰 사이즈 아이콘 1개. 추가로 선택 시 작은 사이즈 아이콘으로 아래에 4개까지 추가
- **수정/클리어/저장:** 기록된 날짜 클릭 시 팝업 호출되어 수정 가능. `[클리어]` 버튼으로 팝업 내 선택 상태를 즉시 초기화할 수 있으며, `[저장]`을 통해 최종 반영

## 필요한 자료
- 아이콘 데이터 준비
  ```javascript
  const icons = ['🏃‍♂️', '📚', '💻', '☕', '🎉'];
  ```
- 색상 데이터 준비
  ```javascript
  const colors = ['#FFB3BA', '#FFDFBA', '#FFFFBA', '#BAFFC9', '#BAE1FF', '#E6B3FF'];
  ```
- **데이터 저장소:** 브라우저 로컬 스토리지 (JSON 형식)

## 완료 기준
- 브라우저 및 모바일 환경에서 완성된 HTML 파일을 열었을 때, 이번 달 달력이 바로 보이고 '오늘 날짜'가 정확히 표시되는가?
- 날짜 클릭 후 팝업이 나타나고 이모지(🏃‍♂️ 등)와 파스텔톤 배경색을 고른 뒤 `[저장]`을 누르면, 달력의 해당 날짜 칸에 내가 고른 색과 이모지가 들어가는가?
- 메인 이모지 1개에서 추가로 아이콘을 선택하면 작은 사이즈로 아래에 배열되는가?
- 저장된 데이터는 새로고침 후에도 로컬 스토리지에서 불러와 화면에 유지되는가?
- `[클리어]` 버튼을 누르면 팝업 내 선택된 아이콘과 색상이 깨끗하게 초기화(리셋)되는가?
- `'주간 뷰'` 버튼을 눌렀을 때, 화면이 한 달 전체에서 '이번 주(일~토)'만 보여주는 깔끔한 형태로 잘 바뀌는가?
- 다시 `'월간 뷰'`로 돌아왔을 때도 레이아웃이 깨지지 않는가?
- 모바일 환경에서 엄지손가락 터치가 편리하도록 버튼과 팝업 영역이 최적화되어 있는가?
- 외부 라이브러리 없이 HTML, CSS, JavaScript 파일 하나로 동작해야 함

## 추가 기능
- **이미지 저장:** 기록된 달력 화면을 고해상도 이미지 파일(PNG 등)로 저장하는 기능
- **데이터 관리:** JSON 파일 내보내기 및 병합/전체 교체를 지원하는 불러오기 기능을 통한 데이터 이전

## 한계 및 비목표
1. 별도의 서버나 데이터베이스를 사용하지 않으므로, 다른 기기와의 데이터 동기화는 지원하지 않음
2. 사용자 계정 로그인 기능은 구현하지 않음
3. 복잡한 통계 기능(월간 기록 분석 등)은 이번 구현 범위에서 제외함

## 검증 방법
- **데이터 저장:** 기록 후 새로고침을 하여 로컬 스토리지의 JSON 데이터와 화면에 표시된 내용이 일치하는지 확인
- **UI 레이아웃:** 아이콘 개수 변화에 따라 입력 및 모바일 환경에서의 터치 편의성 확인
- **기능 대조:** 기획서에 명시된 기능(수정, 클리어, 뷰 전환)을 직접 터치/클릭하여 의도한 동작이 수행되는지 1:1 대조
- **추가 기능 검증:** 이미지 저장 및 JSON 파일 입출력을 통해 데이터가 정상적으로 백업/복원되는지 테스트

---

### 검증 방법 (직접 해보는 테스트 시나리오)
1. **데이터 저장 및 유지 검증**
   * **행동:** 특정 날짜에 아이콘과 색상을 저장한 뒤, 브라우저의 '새로고침'을 누르거나 모바일 브라우저 창을 닫았다가 다시 열어본다.
   * **확인:** 방금 기록한 내용이 날아가지 않고 화면에 그대로 남아있는지 확인한다. (필요시 브라우저 개발자 도구(F12)의 'Application > Local Storage' 탭을 열어 JSON 데이터가 잘 들어있는지 확인한다.)

2. **UI 레이아웃 및 아이콘 배치 검증 (핵심 디자인 규칙)**
   * **행동 1 (1개 선택):** 아이콘을 딱 1개만 선택하고 저장해 본다. (날짜 숫자 아래에 크게 중앙 배치 확인)
   * **행동 2 (여러 개 선택):** 아이콘을 2~5개 선택하고 저장해 본다. (첫 번째 아이콘은 메인 유지, 나머지 최대 4개는 아래에 작은 사이즈로 나란히 배치 확인)
   * **행동 3 (초과 선택):** 아이콘을 6개 이상 선택하려고 시도해 본다. (5개까지만 선택되도록 경고창과 함께 차단되는지 확인)

3. **핵심 기능 동작 검증 (클리어 및 뷰 전환)**
   * **행동:** 기록이 없는 날짜 터치(신규 작성) ➡️ 기록이 있는 날짜 터치 후 `[클리어]` 버튼을 눌러 선택 상태가 리셋되는지 확인 ➡️ `[주간 뷰/월간 뷰]` 버튼 번갈아 터치(뷰 전환)를 순서대로 실행해 본다.
   * **확인:** 각 버튼을 누를 때마다 에러 없이 화면이 즉각적으로 의도한 대로 바뀌는지 확인한다.

4. **추가 기능(백업/공유) 검증**
   * **행동 1 (이미지 저장):** 달력을 예쁘게 꾸민 뒤 `[이미지 저장]` 버튼을 눌러본다. (내 컴퓨터/모바일에 PNG 파일로 다운로드되어 화면 모습 그대로 저장되었는지 확인)
   * **행동 2 (데이터 백업/복원):** `[내보내기]`로 JSON 파일을 받은 뒤, `[불러오기]`를 통해 '병합하기' 또는 '전체 교체'가 정상 작동하여 데이터가 복구되는지 테스트한다.
