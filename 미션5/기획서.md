# 미니멀 활동 기록 캘린더

## 대상 사용자
- 일상을 간단하고 직관적으로 기록하고 싶은 누구나

## 사용 목적
- 날짜별로 아이콘과 색상을 활용하여 활동을 기록하고, 이를 시각적으로 확인하거나 이미지로 공유하기 위함

## 화면 구성과 동작
- 월간/주간 뷰: 기본은 월간 뷰이며, 날짜 클릭 시 해당 날짜가 포함된 주(일~토)의 주간 뷰로 전환 가능
- 날짜 칸: 왼쪽 상단에 날짜 숫자 배치, 배경은 선택한 파스텔톤 색상 적용
- 데이터 입력: 날짜 클릭 시 팝업(모달) 호출. 아이콘(최대 5개)과 색상 선택 가능
- 아이콘 배치: 숫자 아래에 아이콘 나열. 5개를 초과하여 선택 시 아이콘 크기 자동 축소
- 수정/삭제: 기록된 날짜 클릭 시 기존 데이터 불러오기 및 수정/삭제 버튼 제공

## 필요한 자료
- 아이콘 세트: 미리 정의된 아이콘 5종
- 색상 팔레트: 미리 정의된 파스텔톤 색상 5~6종
- 데이터 저장소: 브라우저 로컬 스토리지 (JSON 형식)

## 완료 기준
- 페이지 접속 시 오늘 날짜가 포함된 월간 달력이 자동으로 렌더링되어야 함
- 날짜 클릭 시 팝업이 나타나고, 아이콘과 색상을 선택하여 저장할 수 있어야 함
- 저장된 데이터는 새로고침 후에도 로컬 스토리지에서 불러와 화면에 유지되어야 함
- 주간 뷰 전환 시 해당 주의 데이터만 필터링되어 표시되어야 함
- 아이콘 5개 이상 선택 시 자동으로 크기가 축소되어 칸 안에 배치되어야 함
- 외부 라이브러리 없이 HTML, CSS, JavaScript 파일 하나로 동작해야 함

## 추가 기능
- 이미지 저장: 기록된 달력 화면을 이미지 파일(PNG 등)로 저장하는 기능
- 데이터 관리: JSON 파일 내보내기 및 불러오기 기능을 통한 데이터 이전

## 한계 및 비목표
1. 별도의 서버나 데이터베이스를 사용하지 않으므로, 다른 기기와의 데이터 동기화는 지원하지 않음
2. 사용자 계정 로그인 기능은 구현하지 않음
3. 복잡한 통계 기능(월간 기록 분석 등)은 이번 구현 범위에서 제외함

## 검증 방법
- **데이터 저장:** 기록 후 새로고침을 하여 로컬 스토리지의 JSON 데이터와 화면에 표시된 내용이 일치하는지 확인
- **UI 레이아웃:** 아이콘 개수 변화에 따라 크기가 유연하게 조절되는지 브라우저 개발자 도구로 확인
- **기능 대조:** 기획서에 명시된 기능(수정, 삭제, 뷰 전환)을 직접 클릭하여 의도한 동작이 수행되는지 1:1 대조
- **추가 기능 검증:** 이미지 저장 및 JSON 파일 입출력을 통해 데이터가 정상적으로 백업/복원되는지 테스트
